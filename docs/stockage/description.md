# Description

La fédération de stockage de MesoNET se base sur le logiciel iRods. Ce logiciel permet de répartir les ressources de stockage à travers plusieurs site universitaire.

Données organisées en objets et collection sans importance de localisation physique

Métadata

Offre le choix à l'utilisateur d'où sont stocké ses données. Permet de facilement stocker ses données proches du mésocentre qui les traiteras.
