# Description


## Introduction

La fédération de stockage de MesoNET se base sur le logiciel iRods. Ce logiciel permet de répartir les ressources de stockage à travers plusieurs site universitaire.

Les données sont organisées en objets, équivalent aux fichiers, et collections, équivalent aux dossiers. Cette organisation est sans importance de localisation physique des serveurs de stockage.

Cependant vous avez le choix d'où sont stockées vos données. Cela permet de facilement stocker vos données proches du mésocentre qui les traiteras.

De plus, irods permet d'étiquetter vos données avec des métadonnées.

## Terminologie

* Ressource : Serveur de stockage irods, on les définis par leurs localité. Exemple : Lille, Lyon, Corse, etc...

* Pour simplifier la lecture de la présente documentations, nous utiliserons les termes **fichiers et dossiers** en lieux et place de **objets et collections**.
